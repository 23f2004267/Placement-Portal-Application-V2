
# Placement Portal Application V2

This project is developed for the Modern Application Development II course.

The Placement Portal Application allows Admin, Companies, and Students to interact in a centralized platform to manage placement drives, applications, and recruitment activities.

## Tech Stack

Backend: Flask  
Frontend: VueJS  
Database: SQLite  
Caching: Redis  
Async Jobs: Celery + Redis  
Styling: Bootstrap

## Roles

- Admin (Institute Placement Cell)
- Company
- Student

## Features

- Role based authentication
- Placement drive management
- Student job applications
- Admin approval system
- Placement tracking
